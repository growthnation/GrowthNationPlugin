# GrowthNation — MCP Connector

One connector, no skills bundled: this plugin plugs your agent into your company's
**Agentic Transformation OS** at `https://app.growthnation.ai/mcp` (OAuth — no API keys,
just sign in).

## What your agent gets after signing in

- **Your skill library as tools** — the agent skills GrowthNation generated for YOUR
  departments from voice interviews with your team: security-audited, quality-scored,
  versioned, served fork-first (your personal version when you have one, the team's
  otherwise).
- **Your company's connected tools through one gateway** — Google Workspace (Calendar,
  Drive, Sheets, Docs, Slides, Forms, Ads, Gmail), Slack, Notion, GitHub, Asana,
  Apollo, Fireflies, Fathom, Granola and more — one router tool per connector,
  credentials held server-side.
- **`start-interview`** — kick off your own voice interview; it feeds your
  department's skill library.
- **`department-audit`** — your interview-grounded AI-readiness scorecard.
- **`create-skill`** — propose a new skill into the company library (a manager
  approves; it ships to everyone).
- **`report-feedback`** — tell it when a skill misbehaves; your personal version
  regenerates within ~2 minutes.

openclaw plugins install clawhub:@growthnation/plugin
